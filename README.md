# Wavenumber-Resolved Spectral Gating (WRSG) for Generative Modeling of 2D Turbulence

Single-file reference implementation. All scripts live in `code/`. Everything (DNS, models,
training, evaluation, and all reviewer-response experiments) is in `code/WRSG.py`, with the
standalone scripts for the conditional-rollout and UQ experiments beside it. Paths resolve to
the repository root, so `Dataset/`, `Results/`, and `Checkpoints/` are created next to `code/`
regardless of the working directory.

**Naming.** The method/model is **WRSG**. In the code and the released CSVs/checkpoints the
variant tags are lowercase: `wrsg` = WRSG (gate + losses), `wrsg_gate` = WRSG-gate (gate only),
`wrsg_phys` = WRSG-phys (losses only), `wrsg_fno` = WRSG+FNO (hybrid); `vanilla`, `se`, `fno`,
`fno_operator` are the baselines. The tags are kept lowercase so the code matches the on-disk
CSV columns and checkpoint filenames.

## Repository layout
```
code/         all source; WRSG.py is the single-file implementation (DNS, models, training,
              evaluation, ablations, transfers) with the standalone scripts beside it
Results/
  Tables/     61 CSVs -- every number reported in the paper, including the per-seed tests
  _*_cells/   small per-cell metric dicts (.pt) that the `aggregate` subcommands collect
              into the ablation tables; committed so the tables rebuild without a GPU
paper/        TMLR camera-ready: main.tex, main.bib, main.bbl, figures/, style files, main.pdf
talk/         conference talk (WRSG_TMLR_talk.pptx) and SPEAKER_NOTES.md
requirements.txt, LICENSE (MIT)
```
`Dataset/`, `Checkpoints/`, `Results/figures/` and the queue/ensemble scratch directories are
generated by the code and are not committed (see `.gitignore`); the commands below rebuild them.

## Requirements
Python 3.12 (tested), and the pinned packages in `requirements.txt` (`pip install -r
requirements.txt`). `torch` is the CUDA 12.4 build. Licensed under MIT (see `LICENSE`).

## Reproduce the main results
```bash
python code/WRSG.py --prepare_data_only               # generate + validate the DNS dataset (cached)
python code/WRSG.py --claim_queue --worker_tag gpu0   # train+eval the sweep (launch one per GPU)
python code/WRSG.py --aggregate_only                  # build headline tables + figures
python code/WRSG.py --smoke                            # ~2 min tiny smoke test
```
This regenerates the headline tables end-to-end: `summary_metrics.csv`,
`per_regime_metrics.csv`, `headline_table_with_ci.csv`, `compute_profile.csv`, and the
`seed_level_tests_*.csv` paired tests.

## Regenerate every table (ablations, transfers, UQ, conditional)
```bash
bash code/reproduce_all.sh            # prints the full cell grid; pass `run` to execute it
```
`reproduce_all.sh` enumerates the complete set of ablation/transfer/UQ cells (the bins/rank,
loss-weight, sigma_max, low-k, scalar/cellular/64^2 transfer, and downstream jobs) and the
standalone scripts below, so no manual job list is required.

## Reviewer-response experiments (subcommands)
```bash
python code/WRSG.py reviews ood          # out-of-distribution viscosity
python code/WRSG.py reviews speed        # inference speed (add --cpu for CPU)
python code/WRSG.py reviews steps        # sampling-step sweep
python code/WRSG.py reviews mechanism    # learned-gate probe
python code/WRSG.py reviews rootcause    # spectral-distortion origin
python code/WRSG.py reviews gradflow     # physics-loss gradient flow
python code/WRSG.py reviews uqdepth      # per-regime / per-wavenumber UQ
python code/WRSG.py reviews sweepcell  --bins 8 --rank 2 --seed 29    # gate bin/rank cell
python code/WRSG.py reviews lambdacell --scale 0.5 --seed 29          # loss-weight cell
python code/WRSG.py reviews lambdaLcell --scale 2 --seed 29           # integral-length-weight cell
python code/WRSG.py reviews lowkcell   --lam_lowk 0.1 --seed 29       # low-k spectral-loss cell
python code/WRSG.py reviews losscell   --tag struct0 --seed 29        # loss-configuration probe
python code/WRSG.py reviews sigmacell  --sigma_max 10 --seed 29       # sigma_max cell
python code/WRSG.py reviews aggregate    # collect gate/lambda/sigma cells
python code/WRSG.py reviews lossagg      # collect integral-length / loss-probe cells
python code/WRSG.py reviews figs         # regenerate sample-based figures

python code/WRSG.py secondflow gendata   # passive-scalar transfer (different field)
python code/WRSG.py secondflow traincell --variant wrsg --seed 29 --profile spectral_only
python code/WRSG.py secondflow retuneagg # collect scalar loss-configuration cells
python code/WRSG.py thirdflow  gendata   # cellular-forcing transfer (different flow)
python code/WRSG.py thirdflow  traincell --variant wrsg --seed 29
python code/WRSG.py resolution gendata   # 64^2 resolution transfer (gate bins auto-scaled)
python code/WRSG.py resolution traincell --variant wrsg --seed 29
python code/WRSG.py downstream            # sparse-reconstruction (data-assimilation) demo
```

## Standalone scripts
Conditional next-step emulator (drift comparison, Appendix):
```bash
python code/conditional.py --gpu 0                            # conditional emulator vs WRSG stationary distribution
python code/conditional.py --robust --gpu 0                   # drift-stability + second-seed robustness
```
Uncertainty-quantification analyses (eval-only on the trained checkpoints):
```bash
python code/uq_improve.py    --gpu 0                           # scale-resolved recalibration study (null result)
python code/uq_stochastic.py --variant wrsg --seed 29 --gpu 0 # stochastic-sampler (EDM churn) UQ diagnostic
python code/uq_gen_ens.py    --variant wrsg --seed 29 --gpu 0 # cache a large (n_uq=256) UQ ensemble -> Results/_uqens/
python code/uq_final_eval.py --variant wrsg --gpu 0           # deep-ensemble + split-conformal UQ with bootstrap CIs
```
Short-time Navier--Stokes relaxation (cascade / OOD hybrid, Appendix):
```bash
python code/ns_relax.py --variant wrsg --seed 29 --gpu 0      # relax generated fields under the true solver
```
These write `conditional_comparison.csv`, `conditional_robustness.csv`, `uq_improve.csv`,
`uq_final_<variant>.csv` / `uq_pooled_conformal.csv`, and `ns_relax_<variant>_seed<seed>.csv`.
`uq_final_eval.py` consumes the ensembles cached by `uq_gen_ens.py`, which reuses helpers from
`uq_stochastic.py`. The headline UQ (per-pixel coverage, CRPS) is produced by the main sweep's
evaluation on a regime-stratified cal/test split and lands in `summary_metrics.csv`.

## Notes
- Sampling at evaluation time is seeded (`noise_seed`), so runs are reproducible up to GPU
  floating-point non-determinism: the spectral metrics use CUDA `scatter_add_` (atomic adds),
  so numbers match the committed CSVs to ~1e-5, not bitwise. Set
  `torch.use_deterministic_algorithms(True)` for stricter reproducibility (slower).
- The test split is carved with a fixed seed (0), is identical across every variant/seed, and
  never enters training. The global normalization scale is computed over the full dataset
  (two dataset-level scalars).
- `bash code/run_pool.sh <gpu>` (invoked from the repo root) is an optional file-lock
  claim-queue worker for arbitrary job lists; `bash code/status.sh` prints a progress
  snapshot. `--claim_queue` is the built-in equivalent.
- Outputs: `Results/Tables/*.csv` holds every number in the paper. Manuscript figures are in
  `paper/figures/`; the plotting subcommands regenerate them under `Results/figures/`.

## Data, checkpoints and compute
- **Data.** No external dataset is needed. Every field is generated by the pseudo-spectral DNS
  solver inside `code/WRSG.py`; `--prepare_data_only` writes and validates the cache in
  `Dataset/` (seven viscosity regimes, spun up past the transient, fixed split seed 0).
- **Checkpoints.** Trained weights are not distributed in this repository (git is the wrong
  place for them). Re-run `--claim_queue` to regenerate them; the released CSVs in
  `Results/Tables/` are the record of the reported numbers.
- **Compute.** The full sweep is eight variants x five seeds x 160 epochs at $128^2$:
  **99.4 GPU-hours** of training in total on one V100, peak memory 3.19 GiB. Per seed:
  vanilla 1.85 h, se 1.91 h, fno 2.27 h, fno_operator 2.33 h, wrsg_gate 2.43 h, wrsg_phys
  2.44 h, wrsg 3.15 h, wrsg_fno 3.51 h. Exact per-run times are in
  `Results/Tables/compute_profile.csv`. Use at most three GPUs (one `run_pool.sh` worker each).
- **Seeds.** 29, 47, 89, 101, 149 throughout.
